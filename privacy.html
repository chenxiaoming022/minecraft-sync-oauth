Privacy Policy

Minecraft Sync is a personal application used to synchronize Minecraft world saves through Google Drive and rclone.

Google Drive Access

The application requests Google Drive access to upload, download, and manage files. The OAuth permission allows access to the user's Google Drive files, although the synchronization scripts are configured to use a dedicated Minecraft folder.

Data Storage

Minecraft backup files are stored in the user's own Google Drive account. OAuth credentials are stored locally by rclone and are not published in this website.

Data Sharing

The application does not operate an independent data collection server, sell user data, or use information for advertising.

User Control

The user may delete backup files from Google Drive and revoke OAuth access through Google Account security settings.
